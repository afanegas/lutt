# LUT Timer

A focused workout timer with audio priority optimization for mobile devices.

## Features

- Circular progress timer with visual feedback
- Customizable exercise lists with reps and rest periods (changes not saved between sessions - edit HTML directly or contribute persistence features)
- Audio beeps and voice announcements
- Screen wake lock to prevent dimming
- Optimized for mobile background audio ducking

## Live Demo

👉 [https://afanegas.github.io/lutt/](https://afanegas.github.io/lutt/)

## Usage

Open `index.html` in a web browser. No build process required.
